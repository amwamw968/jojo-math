# 多门槛保证问题的分类讨论 ✳️

有时候要保证好几条数量要求同时成立，比如三种颜色分别不少于 $9$ 个、$6$ 个、$3$ 个。这时要把「还差哪一条没凑齐」分成几种最倒霉的情况，每种都算出「刚好还差一点点」的个数，再取其中**最大**的那个，最后加 $1$。

为什么取最大？因为只要还存在一种拿法，拿了很多却仍然差一条要求，就必须把这种拿法也挡住。答案要能挡住所有最倒霉的情况。

### 例题
红球 $8$ 个、绿球 $10$ 个、黄球 $12$ 个、白球 $15$ 个。要保证三种颜色分别不少于 $3$ 个、$6$ 个、$9$ 个。

- 卡 $9$：每种都只拿 $8$ 个（红球刚好只有 $8$ 个），$8+8+8+8=32$，还没有任何一种到 $9$ 个。再加 $1$ 是 $33$。
- 卡 $6$：白球 $15$ 个全拿（已经超过 $9$），其余三种各拿 $5$ 个，$15+5+5+5=30$，再加 $1$ 是 $31$。
- 卡 $3$：白 $15$、黄 $12$ 全拿（已经够 $9$ 和 $6$），红、绿各只拿 $2$ 个，$15+12+2+2=31$，再加 $1$ 是 $32$。

最大的是 $33$，所以至少取 $33$ 个。

### 易错提醒
- 漏掉其中一种「卡住」的情况，算出的数往往会偏小。
- 每种颜色的总数是上限：红球只有 $8$ 个，就不能在「卡 $9$」里写成拿 $9$ 个红球。
- 三种要求是分给三种**不同**颜色的，不是同一种颜色同时满足 $3$、$6$、$9$。
